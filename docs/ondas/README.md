# Ondas de construção

Uma pasta, um relatório por Onda. O relatório é escrito **no fim da Onda, com os
números medidos** — não no começo, com os números pretendidos.

| Onda | Relatório | Estado |
|---|---|---|
| 1 — Fundação | (no corpo do PR #1) | ✅ mesclada |
| 2 — A jazida viva | [`ONDA-2-JAZIDA.md`](./ONDA-2-JAZIDA.md) | ✅ mesclada |
| 3 — O motor de caça | [`ONDA-3-CACA.md`](./ONDA-3-CACA.md) | 🔨 PR aberto |

## O que um relatório de Onda tem que ter

Isto não é formulário: é a Regra de Pedro aplicada ao próprio relatório.

1. **Responde com prova** — número medido, com o comando que o produziu
2. **Traz o adjacente** — o que apareceu do lado e vale saber
3. **Argumenta contra si** — o que o relatório NÃO pode afirmar, e onde o
   próprio número do autor é frágil
4. **Deixa carga reservada** — o que está pronto e espera o "pode fechar"

E a Lei 7 em cada linha: número medido é medido, número extrapolado é
`🟡 ESTIMATIVA` com a base declarada, e o que não se olhou é `❔ NÃO VERIFICADO`.
